Installing

  1. Install the Tampermonkey browser extension.
  2. Click Build my script above, then Download (or Copy to clipboard).
  3. Open Tampermonkey's dashboard, create a new script, and paste in (or drag in) the downloaded file.
  4. Save. The script activates on the configured CyTube rooms.
